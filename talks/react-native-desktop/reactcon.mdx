# Three ways to draw a desktop app {shared=rnconnection-title shared-resize=preserve class="text-center font-semibold tracking-tight text-7xl"}

<RendererFamilies />

<!--
1. First, a quick desktop framework tour, because most of us spend our time on mobile. There’s basically three ways of doing it.

First is real native UI. AppKit is effectively UIKit on mac. SwiftUI is Apple's newer native framework, same as on mobile. And of course React Native renders native views.

2. Then there are the browser ones. Electron bundles Chromium and Nodejs with your app. Tauri uses the system WebView with a Rust backend.

3. And then there are frameworks that render every pixel on a canvas. Flutter, Compose Multiplatform, and GPUI, which is the Rust framework behind Zed.
-->
