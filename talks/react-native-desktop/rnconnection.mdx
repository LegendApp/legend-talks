# Three ways to draw a desktop app {shared=rnconnection-title shared-resize=preserve class="text-center font-semibold tracking-tight text-7xl"}

<RendererFamilies />

<!--
1. First, a quick desktop framework tour, because most of us spend our time on mobile.

AppKit is basically the macOS equivalent of UIKit. SwiftUI is Apple's newer declarative framework, same as on mobile. And of course React Native macOS uses native views.

2. Then there are the browser ones. Electron brings Chromium and Node with your app. Tauri uses the system WebView with a Rust backend.

For Deno, I tested both a system WebView and bundled Chromium through CEF. Same basic idea: the content is HTML and CSS.

3. And then there are frameworks that draw their own UI. Flutter, Compose Multiplatform, and GPUI, which is the Rust framework behind Zed.

They can all integrate with the OS. But they’re very different in how they run code and power the UI.
-->

<!--
1. Before we get into the numbers, I’ll show you the general architecture of these apps.

First we find the chat files. That's done as natively as possible.

2. Then we parse the metadata. Titles, providers, dates. Enough to show the list of chats without opening every conversation in full.

3. When I select a chat, an extremely optimized C++ parser opens it and splits it by markdown blocks, not a full markdown parse. I expose that through Nitro Modules.

4. Then it goes over to React where LegendList virtualizes the messages and renders them with enriched markdown. The data remains in the native side, it doesn’t copy anything to javascript except block ids and metadata.

5. For each visible markdown row, Enriched Markdown renders it by block ID. So in this case the chat content is rendered natively while React composes the row.

6. And React is where we have the app UI. The layout, the state, what happens when I select another chat. We use some native components like a SplitView and toolbar buttons, but it’s all rendered from React.

7. The composer is a React component too. It handles input and renders a native liquid glass view under it.

8. And settings is all done in React as well, with a native SplitView on the left and a LegendList on the right.

This is regular React Native, with native modules and native views.
