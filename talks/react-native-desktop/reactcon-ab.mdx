<!--
1. Now look at installed size. React Native is about 7 and a half MB.

2. The interesting thing is what each app has to bring with it.

3. AppKit and SwiftUI are tiny because they’re built in to the operating system

4. Electron and Deno CEF build in a full Chromium browser, and a full Nodejs or Deno runtime.

5. GPUI brings its own rendering system, and it’s impressively small. React Native brings Hermes and its own runtime, but it’s still a very small app.

6. I think of these in buckets. React Native is well within the tiny app bucket. A few megabytes doesn’t matter that much in the baseline. But we definitely don't want to be pushing 300 megabytes for a Hello World app.
-->
